# BIC-2026Q4-0417-BOARD-v3

This repository contains the released implementation of the sensor board design package
(revision 3) produced under project GRP-0417, Coastal Sensor Mesh.

## Status

Released on 2026-10-30. The design package is complete, reviewed by the hardware panel and
may be cited in release circulars.

## Contents

- `board/bom.csv` - bill of materials for revision 3
- `board/stackup.md` - layer stack-up and impedance notes
- `src/outline.py` - board outline generator used for the fabrication drawing
